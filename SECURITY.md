# Security policy

If you found a vulnerability in `@keyset/sdk`, `@keyset/cli` or the Keyset API, please tell us privately first. Do not
open a public issue.

Use GitHub's private vulnerability reporting for this repository (the "Report a vulnerability" button under the
Security tab). If that is not available to you, write to the developer-access address on [keyset.dev](https://keyset.dev) and say
"security" in the subject. Please include what you did, what you expected and what happened, and the package version.

We read every report and tell you what we do about it. A key or a secret you found anywhere,
including in this repository's history, counts as a report: tell us and revoke it if it is yours.

Supported versions: the latest 1.x of `@keyset/sdk` and the latest 0.x of `@keyset/cli`.
