# Contributing

Issues are welcome: a bug, a missing type, a documentation gap, a question about the API. Please include the package
version, Node version and the smallest piece of code that shows it.

The source of truth for this code is a private repository. This repository is assembled from it for each release and
overwritten by the next one, so a pull request cannot be merged here as it is. If you have a change in mind, open an
issue with the patch or a description; if we take it, it lands in the source and appears in the next mirror run, and we
say so in the issue.

Changes to the SDK follow the stability rule in [`packages/sdk/VERSIONING.md`](./packages/sdk/VERSIONING.md).
